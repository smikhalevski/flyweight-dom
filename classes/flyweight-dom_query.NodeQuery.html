    Class NodeQuery<TNode>

    The list of selected nodes. A query isn't changed after it is created: each method returns a new query, so a query can be reused as the start of other queries.

    Nodes are ordered as in jQuery: ancestors and preceding return the closest node first, children, next and previous keep the order of nodes they were selected from, and other methods return nodes in document order. Use sort to put nodes in document order.

    ancestors

    • ancestors(localName?: string, namespaceURI?: string | null): NodeQuery

      Selects ancestor elements of nodes that have the given local name and namespace.

      Each element is returned once, even if it is an ancestor of several of nodes. Elements are in reverse document order, so the closest ancestor goes first. Use sort to start with the farthest one.

      Parameters

      • localName: string = '*'

        The local name of elements. The special string * represents all elements.

      • namespaceURI: string | null = '*'

        The namespace of elements, or null for elements without a namespace. The special string * represents all namespaces.

      Returns NodeQuery

    explode

    • explode(): IteratorObject<NodeQuery<TNode>>

      Returns an iterator over queries that hold one of nodes each, so a loop can query from each node:

      for (const $item of $(document).descendants('item').explode()) {
        $item.children('title').text;
      }

      Queries are created as the iterator reaches them, so a loop that stops early doesn't create the rest.

      Returns IteratorObject<NodeQuery<TNode>>

    sort

    • sort(): NodeQuery<TNode>

      Returns a query that holds nodes in document order. Use it after methods that don't sort nodes, such as children, or to start ancestors with the farthest one:

      // The outermost section that contains the heading
      $(heading).ancestors('section').sort().first();

      Nodes of different trees have no order, so trees go in the order of their first nodes.

      Returns NodeQuery<TNode>

    union

      Selects nodes and nodes of the other query, the same as the , in a CSS selector. Each node is returned once, even if both queries have it. Nodes are in document order.

      Nodes of trees that only the other query has go last.
